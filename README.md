本项目是基于原生 JavaScript (ES6+)、HTML5 Canvas 与 Web Audio API 打造的 **1985 年红白机（Famicom / NES）经典游戏《坦克大战（Battle City）》1:1 深度复刻版本**。

项目无需任何构建工具或第三方依赖包，零外部音频资源文件，开箱即玩。在完美保留原版物理手感、关卡数据与 APU 声音合成机制的同时，提供了 **7 种全高精现代化渲染皮肤**、**增强型可视化地图编辑器**、**触屏虚拟摇杆**与**多维度参数自定义调控**。

## 🌟 核心特性

### 1. 1:1 像素级原版 ROM 机制还原
- **原生分辨率与视口布局**：严格按照 NES 256×240 逻辑分辨率排布（208×208 核心战场、13×13 建筑大块 / 26×26 8px 子网格、32px 侧栏信息面板 HUD）。
- **海量 108 关关卡库与特色战役波次**：严格对照原版 ROM `StageDataTable ($F07A)` 完整收录原版前 35 关，并全新扩展至 **108 大关卡**！涵盖八卦阵、千岛之湖、钢铁雄关、迷雾森林、沙漏咽喉、太空入侵者、终焉要塞、决战紫禁之巅等独具特色的地形拓扑，每关均配备定制化的 20 辆敌军波次队列（基础坦克、快速坦克、威力坦克、装甲重坦）。
- **经典物理与手感**：
  - **8px 转弯吸附（Corner Snapping）**：精准还原十字路口换向时的对齐吸附机制，绝不卡墙。
  - **象限微观砖块破坏**：每个 8×8 砖块内建 4 位掩码（TL/TR/BL/BR），支持炮弹横向 10px 范围一次性摧毁双砖、3 星坦克粉碎钢板。
  - **冰面平滑惯性与拟真阻尼减速**：支持全车身多点冰面判定，直行松手后呈现**基于时间摩擦阻尼的非线性平滑减速滑停（由快到慢自然收敛）**，并结合梯次转向延迟（Steering Latency）与转向冲量滑移（Turn Inertia / 180° Reverse Skid），手感真实丝滑且不卡墙。
  - **子弹对撞抵消**：敌我炮弹相撞相互抵消，并伴随微爆粒子动画与金属撞击音效。
  - **完整 6 大道具系统**：头盔防护罩、全屏时钟冰冻、铁铲要塞加固（防实体卡墙）、五角星武器升级、全屏手雷轰炸（支持红坦克战利品保护）、坦克+1生命。
  - **经典双人协作与互坑机制**：双人对战支持互相致盲击晕（3 秒）、通关计分统计结算（Tally Screen）以及战绩领先者 1000 分 Bonus。
  - **生命延续与互借生命（借命）机制**：
    - **生命跨关延续**：彻底取消每局开始强制重置为 3 条命的设定，通关后完整延续上一关剩余的生命数与强化星级。
    - **双人借命复活**：在双人模式中，若一方战死且剩余生命为 0，只要队友仍有备用生命（队友总生命 ≥ 2），阵亡方按下自身的开火键（1P 按 `J` / `Space` / `B`，2P 按 `K` / 小键盘 `0` / `Enter`，或 FC 原版 `A+B`）即可从队友处借得 1 条命并立刻于己方出生点套盾复活，队友生命相应扣减 1 条。HUD 界面在此期间会对可借命状态进行节奏闪烁提示。
  - **108 关最终通关盛典与小学生试卷大奖**：
    - **全屏通关动画**：完成全部 108 关后自动触发终极胜利舞台，伴随原版 NES 2A03 胜利号角音序、60FPS 全屏绚丽粒子烟花、领奖台坦克检阅与专属奖杯；
    - **随机小学语数外试卷大奖通知**：中英文双语弹出终极大奖通知——从【小学语文试卷】、【小学数学试卷】、【小学英语试卷】三样物品中随机抽取一样作为通关大奖，幽默提醒指挥官“今晚作业写完了吗”，顶部控制栏支持“通关大奖”一键演示预览。

### 2. 硬件级 NES 2A03 APU 纯原生音频合成引擎
- **零音频外链，零素材文件**：全套音效由 Web Audio API 动态实时生成，无任何 `.mp3` / `.wav` 外部素材加载负担。
- **4 硬件通道完整模拟**：Pulse 1（方波1）、Pulse 2（方波2）、Triangle（三角波）、Noise（15-bit LFSR 伪随机噪声发生器）。
- **ROM 音序与扫频寄存器级还原**：真实复刻开场 BGM、射击硬件扫频（Sweep）、装甲击中、弹跳反弹、砖块碎裂、基地受袭警报、履带行进轰鸣与通关结算音序，支持跟随游戏倍速同频变速。

### 3. 7 套矢量高清与复古像素双模渲染皮肤
系统内建 4 倍超采样高清矢量与经典像素双渲染管线，可在顶部随时平滑切换：
1. **提瓦特 2D (原神风 / Genshin)**：二次元赛璐璐机甲风格，羽翼图腾基地，风系/水系/雷系粒子流光。
2. **赛博朋克 2D (Cyberpunk)**：等离子悬浮履带、夜之城霓虹边框、电路线路纹理与全息护盾。
3. **二战写实军事 (WWII)**：美军谢尔曼橄榄绿 vs 德军装甲野战灰，写实掩体与沙盘工事。
4. **合金重金属 (Metal Slug)**：经典 SV-001 弹头风格，重装甲涂装与街机爆裂火花。
5. **现代数码迷彩 (Modern)**：M1A2 沙漠数码迷彩、城市战术青、战术雷达基地。
6. **桌面兵棋沙盘 (War Table)**：仿铸铁/黄铜微缩模型棋子，带有木纹、羊皮纸与俯视投影。
7. **经典 FC 1985 (Classic)**：纯正 8-bit 点阵像素，整数倍最近邻点阵插值，原汁原味红白机视效。

### 4. 增强型可视化地图编辑器（CONSTRUCTION Mode）
- **原版 16×16 图块循环**：支持砖墙、半砖、钢板、半钢板、森林、水洼、冰面全套素材。
- **键盘操作**：方向键/WASD 移动光标，空格键循环切换图块形态，`C` 键一键清空地图，`Enter` 保存并立即进入试玩。
- **鼠标涂抹式连续绘制**：支持**按住鼠标左键自由拖动（画笔式）涂抹路障**，右键长按连续擦除，同一格子重复点击可无缝轮换图块。
- **持久化保存**：基于 `localStorage` 自动存储自定义关卡，支持在关卡选择列表中随时作为第 36 关调取。

### 5. 现代化交互与辅助控制
- **CRT 显像管滤镜**：一键开启复古扫描线与屏幕边缘光晕弯曲效果。
- **游戏节奏倍速**：支持 0.75x（慢速研习）、1.0x（原版节奏）、1.2x（高速挑战），音画节拍完美同频。
- **掉落率与弹速调节**：可自定义五角星道具刷新概率（10% ~ 100%）及 0 星初始炮弹飞行速度。
- **双端自适应**：PC 端支持完整快捷键拦截，移动端自适应呼出触控 D-Pad 虚拟方向键与开火按钮。

## 🎮 操作指南

### 1. 游戏控制

#### 单人模式（1 PLAYER）
| 动作 | 键盘按键 | 移动端 / 鼠标 |
| :--- | :--- | :--- |
| **移动** | `W` `A` `S` `D` 或 `↑` `↓` `←` `→` 方向键 | 虚拟十字键（▲ ◀ ▶ ▼） |
| **开火** | `Space`（空格）/ `J` / `Z` / `K` | 虚拟开火按钮 |
| **暂停 / 继续** | `P` / `Enter` / 顶部暂停按钮 | 顶部暂停按钮 |
| **返回主菜单** | `Escape` / 顶部主菜单按钮 | 顶部主菜单按钮 |

#### 双人模式（2 PLAYERS）
| 玩家 | 移动控制 | 开火按键 | 阵亡借命按键（队友生命≥2时） |
| :--- | :--- | :--- | :--- |
| **1P（黄绿色）** | `W` `A` `S` `D` | `Space`（空格）/ `J` / `F` / `G` | `J` / `Space` / `B` / `A+B` |
| **2P（深绿色）** | `↑` `↓` `←` `→` 方向键 | `K` / `L` / 小键盘 `0` `1` / `Slash`（`/`）/ `ShiftRight` | `K` / 小键盘 `0` / `Enter` / `A+B` |

> 💡 **借命规则**：仅在双人模式下有效。当一方阵亡且命数归零（0 命）时，只要队友有备用坦克（队友总生命 ≥ 2，即 HUD 备用坦克显示 ≥ 1），阵亡方按下上方借命按键即可借得 1 条命并立即在出生点套盾重生；队友生命扣减 1 条。若队友仅剩最后 1 条正在驾驶的坦克（总生命为 1），则不可出借。

#### 地图编辑模式（CONSTRUCTION）
| 动作 | 操作方式 |
| :--- | :--- |
| **移动光标** | 方向键 / `WASD` / 鼠标左键点击 |
| **切换图块形态** | 在同一格按 `Space` 或连续点击鼠标左键 |
| **画笔式连续绘制** | **按住鼠标左键并在战场拖动**，自动以当前材质涂抹 |
| **连续擦除** | **按住鼠标右键并在战场拖动** |
| **一键清空地图** | `C` 键 |
| **保存并进入试玩** | `Enter` 键 |
| **退出编辑器** | `Escape` 键 |

## 🚀 快速启动

由于本项目为纯原生前端实现，**无需安装 Node.js、npm 或任何打包工具**。

### 方式一：直接运行
双击根目录下的 `index.html`，使用任意现代主流浏览器（Chrome、Edge、Firefox、Safari）打开即可游玩。

### 方式二：本地静态服务器（推荐）
若需要更标准的运行环境，可通过任意静态服务器启动：

```bash
# 使用 Python 3 启动本地服务器
python -m http.server 8080

# 或使用 Node.js 的 npx serve
npx serve .
```

随后在浏览器中访问 `http://localhost:8080` 即可开始游戏。

## 🛠️ 技术实现要点

1. **固定步长物理循环（Fixed Timestep）**：
   采用 `accumulator` 累加时间差并以固定的 60Hz（16.666ms）执行物理更新与碰撞判定，确保无论显示器刷新率为 60Hz、120Hz 还是 144Hz，坦克移动速度与炮弹弹道均恒定精准。
2. **子弹穿墙与微步防隧穿（Sub-Stepping）**：
   炮弹移动采用子像素细分推进（sub-step），确保在高速炮弹模式下不会发生穿透薄墙或漏碰坦克的隧穿现象。
3. **安全防卡死物理判定**：
   - 坦克在生成点或死角微小接触时，允许“拉开两车间距”的位移判定，杜绝挤压卡死。
   - 铲子要塞要塞加固逻辑动态避让存活坦克，防止墙体重生时将坦克嵌死在实体掩体内。
4. **智能寻路与防振荡 AI 算法**：
   敌军 AI 基于动态 Manhattan 测距向玩家或老鹰靠拢，同时在变向决策中预判前方物理连通性，从源头消除了在死胡同内反复横跳振荡的经典 AI 缺陷。
